## 四、数据迁移方案

### 迁移脚本（3 个）

#### 1️⃣ Redis 数据迁移（元 → 分）
```bash
php migrate_redis_balance_to_cents.php
```
- 扫描所有 `wallet:balance:*` Key
- 将余额 × 100（元 → 分）
- 保持原有 TTL

#### 2️⃣ 迁移验证（随机抽样）
```bash
php verify_migration.php
```
- 随机抽样 100 个玩家
- 对比 Redis（分）vs 数据库（元）
- 允许 1 分误差

#### 3️⃣ 回滚脚本（分 → 元）
```bash
php rollback_redis_balance_to_yuan.php
```
- 紧急回滚用
- 将所有 Redis 数据 ÷ 100

## 六、风险评估

| 风险 | 等级 | 缓解措施 |
|------|------|---------|
| **整数溢出** | 🟢 低 | 添加余额上限检查（100 万元） |
| **迁移期间数据不一致** | 🔴 高 | 采用灰度迁移（双写+优先读新格式） |
| **前端显示错误** | 🟡 中 | 后端统一返回"元"，前端无需改 |
| **第三方金额单位不匹配** | 🟡 中 | 逐一确认游戏平台 API 文档 |
| **浮点数转整数精度丢失** | 🟡 中 | 使用 `(int)round($balance * 100)` |
